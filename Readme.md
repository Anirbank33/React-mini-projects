# ⚛️ React Mini Projects

A collection of small, beginner-friendly React.js projects built while learning React. Each project focuses on one core concept and lives in its own folder.

## 📁 Projects

| # | Project | What it covers |
|---|---------|----------------|
| 01 | [01viteproject](./01viteproject) | Setting up a React app with Vite |
| 02 | [02Counter](./02Counter) | `useState` hook and handling click events |
| 03 | [03Tailwindprops](./03Tailwindprops) | Tailwind CSS and passing props to reusable components |
| 04 | [04 bgchanger](./04%20bgchanger) | Changing the background colour with state and events |
| 05 | [05 Passwordgenerator](./05%20Passwordgenerator) | `useState`, `useEffect`, `useCallback`, `useRef` |
| – | [customReact](./customReact) | Understanding how React renders elements behind the scenes |

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)

## 🚀 How to Run a Project

1. Clone the repository
   ```bash
   git clone https://github.com/Anirbank33/React-mini-projects.git
   ```
2. Go into any project folder
   ```bash
   cd React-mini-projects/02Counter
   ```
3. Install dependencies
   ```bash
   npm install
   ```
4. Start the dev server
   ```bash
   npm run dev
   ```
5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

> `customReact` may be set up differently from the Vite projects. Check its folder for details.

## 🎯 Purpose

These projects are for practicing React fundamentals: components, props, state, hooks, and styling. More projects will be added as I keep learning.
